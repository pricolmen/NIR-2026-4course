# Экспериментальная инфраструктура этап 1

Дата: 2026-11-09. Это этап 1 новой очереди замечаний руководителя — организация серии на нескольких seed. Отчёт не относится к историческому этапу 1 сборки стенда. Разрешён только этот этап; работа останавливается до исследования jitter/потерь и параметров детекторов.

## Что уже существовало

Проверены README, docs/cli.md, docs/experiments.md, реализация generation.cpp/batch.cpp и текущие CLI-контракты. generate уже принимает одну конфигурацию с seed, сохраняет полный JSON/CSV, точную конфигурацию и метаданные. batch уже читает runs с scenario_id/repeat_id/scenario, сортирует метки, выполняет четыре сочетания на одном сохранённом Scenario каждого повтора и пишет comparison/summary. Недоставало организации нескольких конфигураций из шаблона, формирования batch manifest, карты seed→каталоги и проверки повторного использования входов.

## Изменения

- tools/run_seed_series.py: стандартная библиотека Python; генерация по явному списку seed, manifest для реального batch, проверка хешей всех входов и сохранение происхождения. Режим --reuse-series исполняет сохранённые входы без generate. Явный --detector-overrides подготовлен для будущих этапов: изменяет только разрешённые настройки и сохраняет задачи/CSV.
- tests/seed_series_tests.py: восемь целевых проверок организации серии, повторов, некорректных входов и сохранности; CMake регистрирует их одним CTest seed_series.
- docs/seed_series.md и README: команды, форматы, интерпретация seed/повтора и ограничения. .gitignore: разрешены новые Markdown-документы.

C++-алгоритмы, движок, формулы детектора и определения метрик не менялись. В CMake добавлена только регистрация теста; номер реализации остаётся 15. DOCX и текст НИР не изменялись. Полный план следующих исследований в этом этапе не разрабатывался.

## Фактически выполненная проверка

Подготовленная копия /private/tmp/nir-experiment-stage1-work прошла сборку Release и CTest. После переноса изменения заново проверены в основном проекте: build/experiment-stage1-release. Сборка выполнена системными CMake/Ninja с ранее загруженным nlohmann/json 3.12.0; сеть и установка пакетов не требовались.

```sh
cmake -G Ninja -S . -B build/experiment-stage1-release -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DFETCHCONTENT_SOURCE_DIR_NLOHMANN_JSON="$PWD/build/debug/_deps/nlohmann_json-src"
cmake --build build/experiment-stage1-release --parallel 4
ctest --test-dir build/experiment-stage1-release --output-on-failure
```

Результат: **87/87 CTest**, включая один CTest seed_series с восемью проверками Python unittest; время набора 8.63 с. Сборка без предупреждений; C++20, Release/NDEBUG, предупреждения и приватность JSON проверены по compile_commands.json. Фактический --build-info сохранён в series_manifest.json пробной серии.

Лог: build/experiment-stage1-release/verification.log. Это фактический результат текущей версии. Debug и ASan/UBSan на этом этапе заново не запускались: нативная реализация не менялась. Предыдущие числа тестов из исторических отчётов не использовались в качестве результата этапа.

Новая группа seed_series выполнила восемь проверок:

1. Реальная генерация разных входов, соответствие конфигураций шаблону, четыре варианта/хеши и правильная карта каталогов при несортированном списке seed; повтор без генерации, одинаковые содержательные результаты и неизменённая исходная серия.
2. Конфликт --out сохраняет прежние файлы; конечный symlink, включая dangling, отклоняется.
3. Дубликаты/отрицательные/дробные/слишком большие seed отклоняются; 0 и UINT64_MAX принимаются.
4. Повреждённые сохранённые входы отклоняются до нового исполнения.
5. Явная замена настроек детектора сохраняет задачи/CSV и исходную серию; посторонние поля, alpha и вложенный выходной каталог отклоняются. Это тест интерфейса, не исследовательская серия параметров.
6. Decimal и uint64 не сужаются при сохранении JSON; дубликаты ключей и NaN отклоняются.
7. Нативная ошибка generate даёт status=failed, ненулевой выход и сохранённый stderr; серия не объявляется complete.
8. Постоянные диапазоны при разных seed не выдаются за разные наблюдаемые входы; сохраняется distinct_input_sets=1 и пояснение.

## Пробный запуск из корня проекта

```sh
python3 tools/run_seed_series.py --template examples/generator.json --seeds 101 202 --program ./build/experiment-stage1-release/telemetry_sim --out results/experiment-stage1-seeds
python3 tools/run_seed_series.py --reuse-series results/experiment-stage1-seeds --program ./build/experiment-stage1-release/telemetry_sim --out results/experiment-stage1-replay
```

Использован существующий examples/generator.json без изменения: случайные работы 1..4, задержки 0..3 тика, q=0.15, два узла и четыре задачи. Два seed служат проверкой инфраструктуры. Их результаты не являются статистическим сравнением алгоритмов.

Получены **2 разных набора входов**, по четыре завершённых запуска каждого: 8 результатов. Повтор дал ещё 8 результатов; generate не вызывался. Хеши обоих входов, пяти содержательных файлов всех восьми запусков и comparison.csv/summary.csv совпали.

| Seed | Сохранённый вход | Реальный выход batch |
|---|---|---|
| 101 | results/experiment-stage1-seeds/inputs/seed_101 | results/experiment-stage1-seeds/batch/runs/000001 |
| 202 | results/experiment-stage1-seeds/inputs/seed_202 | results/experiment-stage1-seeds/batch/runs/000002 |

Повторные результаты находятся в results/experiment-stage1-replay/batch/, карта — в series_manifest.json каждой серии. Исходные конфигурации — configs/seed_*.json; входы — inputs/seed_*/scenario.json и delivery.csv. Исходный шаблон сохранён как template.json.

Проверена сохранность 695 прежних файлов results/, исходного шаблона и первоначальной пробной серии. Большие исследовательские серии и выводы о качестве алгоритмов не выполнялись.

Первоначальный шаблон, все прежние сценарии/результаты и остальные исходники проверены на сохранность. Служебные manifests разных серий не сравнивались побитово: различаются происхождение, команды и пути. Для воспроизводимости сравнивались точные JSON/CSV входа и пять содержательных файлов каждого варианта. Машинные итоги пробного запуска: build/experiment-stage1-release/probe_checks.json; stdout команд — stage1_probe.log в том же каталоге.

## Границы и следующий этап

Используются стандартные распределения существующего generate. Повторяемость подтверждена для одного бинарника/программной среды. Другие платформы на этом этапе не проверялись. Для генератора разные seed — отдельные псевдослучайные реализации; повторное чтение входа не является новой независимой реализацией. Никаких доверительных интервалов или выводов о превосходстве по двум seed не делалось.

Источник произвольного внешнего бинарника не удостоверяется автоматически: скрипт сохраняет его SHA-256/build-info и доступный снимок исходников отдельно. В данном пробном запуске бинарник собран непосредственно из текущего проекта указанной командой.

Сторонних ошибок, блокирующих этап, не обнаружено. Новых формул, alpha или минимальной sigma не добавлено. Следующий этап — исследование jitter и вероятности потери heartbeat; он требует отдельного поручения. Этап 1 завершён; коммит не создавался, дальнейшие серии не запускались.
