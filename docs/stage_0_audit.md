## Смысловая проверка по плану

| Область | Результат самоаудита |
|---|---|
| Сущности и начальное состояние | Разделены неизменяемый вход, логическая задача/попытка, физическая попытка, оценка и фактическое состояние |
| Граница ядра и движка | Зафиксированы входы/выходы, зависимости, запрет скрытых сведений и RNG в ядре |
| Время и числа | Тик 1 мкс, разные int64-типы, ceil, отдельная стадия SUSPECT, безопасная арифметика, отсутствие epsilon при выборе LL |
| Очереди, Load и RR | Полная исходная работа, однократное снятие, точный ноль пустой нагрузки; сохранение следующего ID и совместное изменение доступности |
| Детекторы | Первый реальный интервал, выборочная дисперсия, прогрев, окно, замороженные пороги, два срока от контакта, поколения и терминальный FAILED |
| Crash и отзыв | Физический crash не сообщается ядру; совместный сортированный возврат, полный повтор; ложный FAILED не останавливает физическую очередь |
| Результаты и фазы | Совпадение тройки назначения; отказ старым результатам; восемь фаз, стабильные ключи, границы перерыва и горизонта |
| Метрики | Единственные определения Load/Recovery; FP не переклассифицируется, crash после FP учитывается отдельно; P95 и окно throughput заданы точно |
| Форматы и повторяемость | Общая полная трасса, неизменяемые входы, отдельное состояние вариантов, канонический журнал, причины отсутствующих значений |
| Прослеживаемость | Каждый блок связан с планируемым модулем, этапом и проверкой; отсутствующий код явно обозначен как будущий |
| Критерий этапа 0 | Отделены правила плана, параметры сценария и дополнительные технические решения; примеры не объявлены научными результатами |

Формула ранга P95 `n - floor(n/20)` равна `ceil(19*n/20)` для положительного целого `n` и избегает умножения с возможным переполнением. Это эквивалентная запись заданного ближайшего ранга, не новое определение метрики.

Содержательных противоречий с моделью плана при самоаудите не выявлено. Технические решения о типах ID, вещественном типе, допуске проверки сумм и порядке видов таймеров явно помечены; они ещё должны пройти программные проверки на своих этапах.
