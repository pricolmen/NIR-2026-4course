# GUI КР Этап 2 Воспроизведение журнала и итоги

Дата: 2026-11-15. Этап 2 выполнен по отдельному разрешению пользователя после завершения проверки этапа 1. Код этапа 1 перед этим прошёл 97/97 полного CTest, 26 Qt Test в Cocoa и отдельный CLI без Qt. Результаты первого этапа сохранены. Текст КР не редактировался, этапы 3/4 не выполнялись.

## Реализация

Окно разделено на настройку, ход просмотра и итоги. Добавлены gui/replay.hpp, replay.cpp, replay_data.cpp, playback_widget.hpp/cpp и tests/replay_tests.cpp; расширены RunResult/загрузка, MainWindow и CMake/инструкция. Проекция строится только по журналу: crash меняет фактическое состояние, before/after наблюдений — оценку детектора, reconfiguration.revoked связывается с assignment.task.id и attempt_no. Приём/отклонение записывается для соответствующей попытки. Пороги, выбор исполнителя, обработки/сети и метрики внутри GUI не вычисляются. Частная зависимость JSON относится только к GUI, расчётные библиотеки не связаны с Qt.

Порядок исходных записей сохраняется, включая одинаковое time_ticks и служебные границы. Один шаг применяет одну запись и приостанавливает просмотр. Таймер использует монотонное время и нормализует весь горизонт к 8 секундам при ×1, сохраняя позицию при паузе/смене скорости. Степень точности ожидания зависит от таймера ОС; модельные отметки показываются исходными целыми. ID uint64 читаются без преобразования через double. При смене результата старый просмотр останавливается/сбрасывается.

Итоги взяты из metrics.json и явно помечены как относящиеся ко всему прогону. Добавлены P95 и таблица Detection/Recovery/классификации по узлам. null имеет понятную причину с исходным reason, не заменяется нулём. Исходник/режимы/уникальный каталог отображены отдельно от текущего выбора нового сценария. При длинной истории есть прокрутка; последние события проверены на видимость. История хранится в памяти, поэтому её объём растёт с журналом. После просмотра Cocoa-снимка уплотнены итоги и высота таблицы узлов: последние строки истории видны на реальной высоте экрана без прокрутки внешней панели. Добавлена проверка этой видимости, обе GUI-группы и живой набор повторно прошли.
