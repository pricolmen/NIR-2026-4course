# Ручной пример: baseline

Два узла p=1 000 000, четыре задачи в 0 с работой [4,2,4,2], H=10, tau0=20, kappa=2, горизонт 20. Трасса без потерь/задержки. После интеграции RR должен назначить [1,2,1,2] и получить завершения по ID [4,2,8,4]. Эти ожидания взяты из ручного примера плана; на этапе 9 проверяется загрузка файлов, полный запуск ещё не реализован.

Это проверочный сценарий, а не доказательство преимущества алгоритма. Все времена — целые микросекундные тики.
