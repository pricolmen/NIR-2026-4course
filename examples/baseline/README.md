# Ручной пример: baseline

Два узла p=1 000 000, четыре задачи в 0 с работой [4,2,4,2], H=10, tau0=20, kappa=2, горизонт 20. Трасса без потерь/задержки. На этапе 10 сквозной запуск fixed/adaptive RR назначает [1,2,1,2] и получает завершения по ID [4,2,8,4], как в ручном примере плана. Fixed/adaptive LL назначает [1,2,2,1] и завершает [4,2,6,6]. Эти значения проверяются integration_baseline.

Это проверочный сценарий, а не доказательство преимущества алгоритма. Все времена — целые микросекундные тики.
