# Ручной пример: blackout

Два узла, H=5, tau0=10, kappa=2, горизонт 40. Получения узла 1 в [10,21) теряются. При нулевой задержке последнее сообщение перед перерывом приходит в 5, следующее — в 25. После интеграции fixed ожидает SUSPECT в 15; сообщение в 25 должно прийти до проверки FAILED той же отметки и вернуть ALIVE. На этапе 9 проверяется загрузка; интегрированный прогон ещё не выполнен.

Это проверочный сценарий, а не доказательство преимущества алгоритма. Все времена — целые микросекундные тики.
