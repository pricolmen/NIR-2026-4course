# Ручной пример: blackout

Два узла, H=5, tau0=10, kappa=2, горизонт 40. Получения узла 1 в [10,21) теряются. При нулевой задержке последнее сообщение перед перерывом приходит в 5, следующее — в 25. На этапе 10 fixed/adaptive даёт SUSPECT в 15; сообщение в 25 приходит до проверки FAILED той же отметки и возвращает ALIVE. Во всех четырёх сочетаниях детектора и распределения это проверяется integration_blackout.

Это проверочный сценарий, а не доказательство преимущества алгоритма. Все времена — целые микросекундные тики.
