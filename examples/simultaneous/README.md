# Одновременные исключения

Три узла p=1 000 000, H=2, tau0=4, kappa=2, горизонт 40. Узлы 1 и 2 получают heartbeat в 2 и физически падают в 3. Шесть задач приходят в 0 с работой [10,9,1,2,3,1], задача 7 — в 10 с работой 1. Тики микросекундные, CSV содержит и потенциальные отправки после crash.

Оба детектора ещё не прогреты для узлов 1/2: SUSPECT в 6, FAILED в 10. В фазе 6 отметки 10 один общий пакет исключает [1,2]. Возвращаемые задачи сортируются по исходному поступлению/ID; затем фаза 7 добавляет задачу 7, и только после неё один dispatch распределяет весь набор на узел 3. Detection=7 для обоих отказов.

RR возвращает [1,2,4,5], затем назначает 7. Завершения по ID [20,29,1,31,34,2,35]; Recovery узлов 1/2 — 28/31. LL возвращает [1,2], затем назначает 7; завершения [20,29,1,3,6,7,30], Recovery 17/26. Все семь задач завершаются; возврат не удваивает число задач.

Проверка: examples_simultaneous в четырёх вариантах с повторным чтением. Значения — ручные контрольные ожидания для этой маленькой трассы, не исследовательское сравнение. [Все примеры](../README.md).
