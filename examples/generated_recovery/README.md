# Сохранённый контрольный результат генератора

Небольшой материализованный сценарий создан командой generate из [generator_recovery.json](../generator_recovery.json), seed=1304, generator_version=1. Точные настройки сохранены в generator_config.json, фактические компилятор/платформа/стандартная библиотека и контрольные суммы — в generation_manifest.json. Входы записаны до моделирования.

Два узла p=1 000 000, горизонт 20, H=1, tau0=4, kappa=2. Три задачи с работой 6 приходят в 0/1/2. Узел 1 физически падает в 3; blackout [1,21) подавляет его сообщения до crash, начальный контакт остаётся 0. Задержка 0, q=0. CSV содержит все 40 потенциальных отправок двух узлов, включая отправки после crash. Времена — целые микросекундные тики.

Во всех четырёх вариантах назначения исходно [1,2,1]. Узел 1 становится SUSPECT в 4 и FAILED в 8: Detection=5. Задача 2 завершается в 7, задачи 1/3 возвращаются в 8 и выполняются полностью на узле 2, заканчиваясь в 14/20. Принятые завершения по ID [14,7,20], Recovery=20-3=17. Завершение на горизонте включается. Баланс 3=3+0, два повторных назначения, FP/FN=0.

Проверка examples_generator повторно генерирует сохранённые JSON/CSV, сравнивает их байты с этим снимком, затем заново читает их для run/compare и пересчёта. Постоянная работа и фиксированные доставки служат ручной проверке, не статистическому сравнению и не доказательству преимущества алгоритма. [Команды и весь каталог](../README.md).
