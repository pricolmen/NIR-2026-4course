# Ручной пример: crash

Два узла, четыре задачи в 0, H=5, tau0=10, kappa=2, горизонт 40. Узел 1 физически падает в 3. Трасса содержит и потенциальные отправки после crash, одинаковые для всех будущих вариантов. После интеграции работа узла 1 должна остановиться в 3, а ядро узнает об отказе только через тайм-ауты. На этапе 9 проверяется загрузка; метрики ещё не вычисляются.

Это проверочный сценарий, а не доказательство преимущества алгоритма. Все времена — целые микросекундные тики.
