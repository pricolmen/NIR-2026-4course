# Отсутствие всех доступных узлов

Два узла физически падают в 0. H=2, tau0=4, kappa=2, горизонт 16; первого реального heartbeat нет. Задачи 1/2 приходят в 0 с работой 3/2, задача 3 — в 4 и задача 4 — в 8 с работой 1. Все времена — микросекундные тики.

Начальная логическая оценка ALIVE не содержит знания о crash. Поэтому задачи 1/2 получают назначения в фазе 8 времени 0, после физических crash фазы 1, но не начинают исполняться. В 4 оба узла становятся SUSPECT, доступных ALIVE нет, без отзыва старых назначений. В 8 один пакет FAILED возвращает задачи 1/2 после уже ожидающей задачи 3; затем поступает задача 4. Итоговый FIFO [3,1,2,4], новых назначений нет.

Во всех четырёх вариантах N_in=4, done=0, unfinished=queued=4, assigned=0; у задач 1/2 одна попытка, у 3/4 — ноль. Оба отказа корректно обнаружены: Detection=8. Recovery отсутствует с recovery_incomplete, latency/P95 — с empty_sample, throughput=0. Это успешный запуск до горизонта с корректно учтённой незавершённостью, а не ошибка или потеря задач.

Проверка: examples_no_alive и общая серия examples_batch; повторная загрузка даёт тот же журнал. Пример проверяет учёт, без вывода о преимуществе алгоритмов. [Все примеры](../README.md).
